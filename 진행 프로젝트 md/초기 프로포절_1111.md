## 1. 연구 요약과 확정된 범위

특정 대여소 또는 위도·경도로 지정한 위치에 있는 **재배치 트럭 1대**가 인근 따릉이 대여소를 방문한다. 각 대여소의 현재 재고와 목표 재고를 비교하여 과잉 대여소에서 자전거를 수거하고 부족 대여소에 배치한다. **어디를 어떤 순서로 방문하고, 각 대여소에서 몇 대를 수거·배치할지 함께 결정하여 총 재배치 비용을 최소화**한다.

| 구분 | 현재 확정된 연구 방향 |
| --- | --- |
| 재배치 주체 | 관리자가 운행하는 트럭 1대 |
| 출발 | 특정 대여소 또는 지정한 좌표 1곳 |
| 대상 | 출발 위치 인근의 여러 대여소 |
| 수거 대상 | 현재 재고가 목표 재고보다 많은 대여소 |
| 배치 대상 | 현재 재고가 목표 재고보다 적은 대여소 |
| 공통 입력 | 위치, 대여소 간 거리·이동비용, 현재·목표 재고, 트럭 적재 한도 |
| 결정사항 | 방문 대상, 방문 순서, 수거량, 배치량, 구간별 트럭 적재량 |
| 연구 방법 | 고전 최적화 기준 해와 동일 문제의 QPU용 인코딩 및 해법 비교 |

**여기서 ‘포화’는 목표 재고 초과를 뜻하는 ‘과잉’으로 표현한다.** 거치대가 물리적으로 모두 찼다는 뜻과 구분한다. 출발지로부터의 거리는 후보 대여소 선정에 사용하고, 실제 경로 비용에는 대여소 사이의 이동도 포함한다.

초기 적재량, 목표 재고 산정법, 탐색 반경, 트럭 용량의 수치, 복귀 여부, QPU 플랫폼은 아직 확정되지 않았다. 이 문서가 새로 제안하는 설정을 기존 합의로 간주하지 않는다.

## 2. 연구 목적과 연구질문

### 연구 목적

1. 따릉이의 국소적인 재고 불균형을 단일 트럭의 수거·배치 경로 문제로 정식화한다.
2. 이동과 상하차의 운영비용, 작업 후 남는 재고 불균형을 함께 고려하는 고전 최적화 모형을 구축한다.
3. 같은 문제를 QPU용 이진 최적화 모형으로 변환하고, 인코딩에 따른 자원 사용과 해의 품질을 비교한다.

### 연구질문

- **RQ1.** 거리만 고려한 근거리 우선 방식과 비교하여, 방문 순서·적재량·작업량을 함께 최적화하면 이동비용과 잔여 부족·과잉이 어떻게 달라지는가?
- **RQ2.** 원래 문제의 실행 가능한 해와 목적함수를 보존하면서 경로·수량·적재 제약을 QPU용으로 표현할 수 있는가?
- **RQ3.** 정수 수량을 이진 자리값과 원핫 방식으로 표현할 때 논리 변수 수, 상호작용 수, 제약 충족률, 최적해 대비 차이는 어떻게 달라지는가?
- **RQ4.** 대여소 수, 트럭 용량, 초기 적재량, 수급 불균형이 변할 때 고전·QPU·하이브리드 접근의 적용 가능한 규모와 한계는 무엇인가?

연구의 기여 후보는 **동일한 재배치 문제에서 인코딩의 정확성·자원 부담·실행 성능을 검증하는 것**이다. 양자 우위는 가정하지 않으며, 성능 개선 여부는 실험 결과로 판단한다. 신규성의 최종 주장은 추가 문헌 검토 후 정한다.

## 4. 문제정의와 1차 모형의 가정

**입력:** 출발 좌표, 후보 대여소 집합, 대여소별 현재·목표 재고, 대여소 간 이동비용, 트럭 용량과 초기 적재량.  
**출력:** 방문 대여소의 순서, 각 방문의 수거량·배치량, 이동 구간별 적재량, 작업 후 재고와 비용 내역.

다음은 구현을 시작하기 위한 **제안 가정이며 미확정 사항**이다.

| 항목 | 1차 모형 제안 | 적용 이유와 범위 |
| --- | --- | --- |
| 시간 처리 | 한 시점의 재고를 고정한 정적 문제 | 계산 중 발생하는 신규 대여·반납을 제외하여 인코딩 검증에 집중 |
| 방문 | 대여소별 최대 1회 방문, 일부 대여소 미방문 허용 | 초기 모형의 규모 제한. 재방문 허용 모형과 해가 달라질 수 있음 |
| 시작·종료 | 출발 위치로 복귀하는 경로 | 아래 수식의 기준. 개방형 경로를 택하면 종료 조건을 수정 |
| 초기 적재량 | 입력값으로 고정 | 빈 트럭과 사전 적재 시나리오를 비교할 수 있음 |
| 종료 적재량 | 0부터 트럭 용량까지 허용 | 지리적 복귀와 적재량 원상복구는 별도 조건임 |
| 작업 방향 | 과잉소에서 수거, 부족소에 배치하며 목표를 넘기지 않음 | 확정된 작업 목적을 직접 표현 |
| 목표 달성 | 잔여 부족·과잉을 허용하고 비용에 반영 | 후보 구역의 총수급이 맞지 않아도 문제를 풀 수 있게 함 |
| 대여소 수용 상한 | 확인한 운영상 상한 또는 명시적 실험 가정 사용 | 공개된 거치대 수를 곧바로 절대 수용 상한으로 보지 않음 |

출발 위치가 대여소라면 **트럭의 출발 노드와 재고를 가진 대여소 노드를 논리적으로 분리**한다. 출발 대여소에서도 작업하도록 정할 경우 해당 대여소를 후보 집합에 한 번만 넣고, 같은 좌표의 출발 노드에서 연결한다. 출발·종료용 가상 노드에는 재고를 중복 부여하지 않는다.

정적 모형의 결과는 입력 시점에 대한 작업 계획이다. 실제 운행 중 서비스 개선 효과는 별도의 시뮬레이션이나 현장 검증 없이 확정할 수 없다.

### 5.2 목표 재고와 전처리 원칙

- 목표 재고는 아직 정해지지 않았다. 초기 검증에는 **외부에서 명시한 정수 목표값**을 사용하고, 실제 데이터 분석 시 운영기준 또는 과거 수요를 이용하는 방식을 결정한다. 단순 비율을 쓰면 공식 운영목표가 아닌 실험 가정으로 표시한다.
- 부족량은 D_i = max(t_i − b_i, 0), 과잉량은 E_i = max(b_i − t_i, 0)로 계산한다. 같은 대여소에서 D_i와 E_i가 동시에 양수일 수 없다.
- 좌표 오류, 결측 재고, 중복 ID, 자료 간 기준일 차이, 폐쇄 대여소를 점검한다. 확인한 상한보다 관측 재고가 크면 임의로 잘라내지 않고 상한 정의와 데이터를 재검토한다.
- 반경 R 또는 가까운 k개 대여소로 후보를 정한다. 공급·부족 비율을 맞추기 위해 후보를 추가하면 별도 선정 규칙으로 기록한다.
- 최적화 전후 및 모든 해법에서 같은 원자료·목표 재고·후보 집합을 사용한다. 목표 산정에 평가 시점 이후의 정보를 사용하지 않는다.
- 합성 데이터는 수식 검증용, 실제 데이터는 사례 분석용으로 구분한다. 현재 문서에는 실제 재고 스냅샷이나 원본 그래프 파일이 첨부되어 있지 않다.

## 6. 그래프 구성

### 6.1 공통 재배치 그래프

G = (V, A), V = N ∪ {s, e}로 정의한다. N은 후보 대여소, s는 트럭 출발 노드, e는 종료 노드다. 복귀형에서는 s와 e의 좌표가 같다.

- **대여소 노드:** 위치, 현재 재고, 목표 재고, 부족량·과잉량, 확인한 수용 상한을 가진다.
- **방향 간선:** 트럭이 이동할 수 있는 두 지점 사이의 거리·시간·비용을 가진다. 대여소 사이의 자전거 자동 이동을 뜻하지 않는다.
- **초기 구성:** s→대여소, 대여소→대여소, 대여소→e 및 무작업 경로 s→e를 포함한다. 자기 간선, s로 들어가는 간선, e에서 나가는 간선은 제외한다.
- **거리:** 좌표 기반 Haversine 거리는 후보 탐색 및 초기 실험의 근사값으로 사용할 수 있다. 운행 경로 분석에는 트럭이 이동할 수 있는 도로 거리·시간이 더 적절하며, 일방통행 때문에 방향별 값이 다를 수 있다.
- **주의:** 출발지와 각 대여소만 연결하는 별 모양 그래프로는 연속 방문 경로의 비용을 표현할 수 없다. 후보를 반경으로 제한하더라도 후보 간 이동비용은 계산한다.

### 6.2 QPU용 계산 그래프

| 구분 | 노드의 의미 | 간선의 의미 |
| --- | --- | --- |
| 공통 재배치 그래프 | 실제 대여소 또는 출발·종료 위치 | 트럭의 이동 가능 관계와 이동비용 |
| QUBO 논리 그래프 | 경로 선택, 수량 비트, 적재량 비트, 보조변수 등 이진 결정변수 | 목적함수·제약에서 생기는 이차 상호작용 |
| 장치에 배치한 그래프 | 해당 플랫폼에서 사용하는 물리 자원 | 장치에서 구현하는 상호작용 |

대여소 하나가 계산 변수 하나에 대응할 필요는 없다. 방문 여부만 이진변수로 두면 수량과 순서를 결정할 수 없어 추가 변수가 필요하다. 장치에 맞춘 변환은 제약과 해의 해석을 보존해야 하며, 연결을 임의로 제거한 결과를 원래 문제와 동일하다고 간주하지 않는다.

## 7. 고전 최적화 모형 초안

아래는 **복귀형·대여소별 최대 1회 방문·부분 재배치**를 기준으로 한 MILP 초안이다. 이 가정들이 확정된 운영정책이라는 의미는 아니다. 모든 간선 합은 허용된 간선 A에 대해서만 계산한다.

### 7.1 집합·매개변수·변수

| 기호 | 의미 |
| --- | --- |
| N, n | 후보 대여소 집합, 그 크기 |
| b_i, t_i, K_i | 현재 재고, 목표 재고, 모형에서 사용하는 수용 상한 |
| D_i, E_i | 초기 부족량, 초기 과잉량 |
| Q, Q_0 | 트럭 최대 적재량, 출발 적재량 |
| c_ij | 구간 이동비용. 거리 또는 시간에서 산정한 값 |
| c_h, c_v | 자전거 1대당 상하차 비용, 대여소 1회 방문의 고정 작업비용 |
| lambda_−, lambda_+ | 잔여 부족·과잉 1대당 비용 가중치 |
| x_ij ∈ {0,1} | i에서 j로 이동하면 1 |
| y_i ∈ {0,1} | 대여소 i를 방문하면 1 |
| p_i, d_i ≥ 0, 정수 | i에서 수거하는 대수, i에 배치하는 대수 |
| f_ij ≥ 0, 정수 | 구간 i→j를 이동할 때 트럭에 실린 자전거 수 |
| r_i ≥ 0, 정수 | 작업 후 대여소 재고 |
| u_i^−, u_i^+ ≥ 0, 정수 | 작업 후 남는 부족량·과잉량 |
| o_i ≥ 0, 정수 | 분리된 순환 경로를 방지하는 방문 순서 보조변수 |
| Q_end ≥ 0, 정수 | 종료 시 트럭 적재량 |

정상 입력은 0 ≤ b_i, t_i ≤ K_i와 0 ≤ Q_0 ≤ Q를 만족해야 한다. 상한이 확인되지 않았다면 K_i는 명시적으로 설정한 실험 상한이며, 실제 물리 용량으로 해석하지 않는다.

### 7.2 목적함수

$$
\min F = \sum_{(i,j)\in A} c_{ij}x_{ij}
 + c_h\sum_{i\in N}(p_i+d_i)
 + c_v\sum_{i\in N}y_i
 + \lambda_-\sum_{i\in N}u_i^-
 + \lambda_+\sum_{i\in N}u_i^+ .
$$

첫 세 항은 이동·상하차·정차의 운영비용이고, 마지막 두 항은 작업 후 남는 재고 불균형의 비용이다. 원화 환산 근거가 없다면 **실험용 가중 비용**으로 보고하고 실제 절감액이라고 표현하지 않는다. 거리·시간·대수의 단위와 가중치를 명시한다.

이동비용만 최소화하면 아무 작업도 하지 않는 해가 선택될 수 있다. 따라서 재배치의 목적을 잔여 불균형 비용으로 반영한다. 가중치에 따라 무작업이 최적인 경우도 있으므로 이동비용과 부족·과잉 해소량을 분리 보고한다. 정책상 일정 수준의 개선이 필수라면 최소 해소량 제약을 추가하되, 모든 비교 방법에 동일하게 적용한다.

### 7.3 경로와 방문 제약

$$
\sum_{j:(s,j)\in A}x_{sj}=1,\qquad
\sum_{i:(i,e)\in A}x_{ie}=1.
$$

$$
\sum_{j:(i,j)\in A}x_{ij}
=\sum_{j:(j,i)\in A}x_{ji}=y_i\qquad(i\in N).
$$

출발·종료는 각각 한 번이며 방문한 대여소에는 한 번 들어가고 한 번 나온다. s→e를 선택하면 무작업 경로가 된다. 다음 순서 제약은 출발지와 연결되지 않은 별도 순환 경로를 방지한다.

$$
y_i\le o_i\le n y_i,\qquad
o_j\ge o_i+1-(n+1)(1-x_{ij})\quad(i,j\in N,\ i\ne j).
$$

### 7.4 수거·배치와 대여소 재고

$$
0\le p_i\le E_i y_i,\qquad 0\le d_i\le D_i y_i.
$$

$$
r_i=b_i-p_i+d_i,\qquad 0\le r_i\le K_i.
$$

$$
r_i-t_i=u_i^+-u_i^-,\qquad
0\le u_i^-\le D_i,\quad 0\le u_i^+\le E_i.
$$

방문하지 않으면 작업량은 0이다. 과잉 대여소에서는 목표를 초과한 수량까지만 수거하고, 부족 대여소에는 목표에 모자란 수량까지만 배치한다. 이 구조에서는 같은 대여소에서 수거와 배치가 동시에 양수가 될 수 없다.

### 7.5 트럭 적재량과 자전거 보존

$$
0\le f_{ij}\le Q x_{ij}\qquad((i,j)\in A).
$$

$$
\sum_{j:(i,j)\in A}f_{ij}
-\sum_{j:(j,i)\in A}f_{ji}=p_i-d_i\qquad(i\in N).
$$

$$
\sum_{j:(s,j)\in A}f_{sj}=Q_0,\qquad
\sum_{i:(i,e)\in A}f_{ie}=Q_{end},\qquad 0\le Q_{end}\le Q.
$$

즉 **다음 적재량 = 현재 적재량 + 수거량 − 배치량**이며, 모든 이동 구간에서 0 이상 Q 이하이다. 빈 트럭은 먼저 수거하지 않으면 배치할 수 없다. 외부 공급이나 폐기를 허용하지 않으므로 다음 보존식도 성립한다.

$$
\sum_{i\in N}r_i+Q_{end}=\sum_{i\in N}b_i+Q_0.
$$

종료 적재량을 Q_0 또는 0으로 고정하는 정책은 추가 결정사항이다. 예를 들어 Q_end = Q_0라면 총배치량과 총수거량이 같아야 한다. 목표 재고를 모두 맞추려면 총량 보존 외에도 용량과 방문 순서에 맞는 운반 경로가 존재해야 한다.

필요 시 이동시간과 상하차 시간을 합한 작업시간 상한을 추가한다. 시간 상한을 사용할지는 아직 미확정이며, QPU 변환 시에도 같은 시간 조건을 유지해야 한다.

### 7.6 수식 확인용 작은 예시

아래 수치는 실제 따릉이 관측값이 아닌 **설명용 합성 데이터**다. Q = 5, Q_0 = 0으로 둔다.

| 대여소 | 현재 재고 | 목표 재고 | 작업 |
| --- | ---: | ---: | --- |
| A | 10 | 6 | 4대까지 수거 가능 |
| B | 1 | 4 | 3대 부족 |
| C | 0 | 1 | 1대 부족 |

`s → A(4대 수거) → B(3대 배치) → C(1대 배치) → e`의 구간 적재량은 `0 → 4 → 1 → 0`이다. 모든 목표를 맞추는 실행 가능한 예시이지만, 이동비용을 주지 않았으므로 최적 경로라는 뜻은 아니다.

## 8. QPU용 인코딩과 고전·양자 비교

### 8.1 비교할 인코딩 초안

QPU 플랫폼은 미확정이다. 우선 위 MILP의 유한 정수변수와 선형 제약을 **QUBO/Ising 후보 모형**으로 변환하여 정확성과 크기를 검증한다. D-Wave 문서는 제약을 벌점으로 바꾸는 이진 모형과 QPU·하이브리드 활용을 설명한다. 이는 플랫폼 선택을 확정한다는 뜻이 아니다. [공식 모형 변환 문서](https://docs.dwavequantum.com/en/latest/quantum_research/reformulating.html).

| 후보 | 수량 a ∈ {0,…,U} 표현 | 비교할 특성 |
| --- | --- | --- |
| A: 이진 자리값 | 여러 비트의 가중합으로 a 표현 | 비트 수는 약 ceil(log2(U+1)). 큰 계수와 수치 범위에 주의 |
| B: 원핫 | a = Σ(q v_q), Σv_q = 1, q = 0,…,U | U+1개 비트와 선택 제약 필요. 작은 수량 범위에서 해석이 쉬움 |

주 비교 대상은 수거량·배치량·구간 적재량의 표현 방식이다. 경로 변수와 나머지 보조변수의 처리 원칙은 고정하여 인코딩 효과를 구분한다. 상한 0인 변수는 상수로 제거한다. 보조변수까지 포함한 전체 변수 수를 보고한다.

이진 자리값은 U가 2의 거듭제곱보다 하나 작은 값이 아닐 때 상한을 넘는 비트 조합을 처리해야 한다. 예를 들어 U = 5라면 가중치 (1, 2, 2)를 쓰는 유계 표현으로 0~5만 만들 수 있다. 표현의 중복은 표본 빈도에 영향을 줄 수 있으므로 기록한다. 일반 이진 표현에 상한 제약을 추가하는 방식도 가능하나, 두 방식을 섞어 보고하지 않는다.

### 8.2 제약의 QUBO 변환

모든 정수변수에 유한한 범위를 정하고, 부등식에는 범위가 정해진 비음수 슬랙 변수를 도입한다. 예를 들면 다음과 같다.

$$
p_i\le E_i y_i
\quad\Rightarrow\quad E_i y_i-p_i-a_i=0,\quad 0\le a_i\le E_i.
$$

$$
f_{ij}\le Qx_{ij}
\quad\Rightarrow\quad Qx_{ij}-f_{ij}-h_{ij}=0,\quad 0\le h_{ij}\le Q.
$$

경로 연결, 방문 순서, 재고와 적재량 보존도 같은 원칙으로 변환한다. 순서 제약을 누락하면 별도 순환 경로가 생길 수 있다. 각 슬랙의 상한은 식의 변수 범위로부터 계산한다. 이진화 후 선형 등식 g_k(z) = 0의 제곱을 더한다.

$$
\min H(z)=F_{original}(z)+\sum_k A_k[g_k(z)]^2,\qquad z\in\{0,1\}^m.
$$

위 초안에서는 g_k가 이진변수의 선형식이므로 제곱해도 이차식이다. A_k는 **하드 제약 위반 벌점**이며, 잔여 불균형을 평가하는 lambda와 역할이 다르다. 벌점의 크기, 계수 정규화, 장치의 수치 정밀도를 함께 검토한다.

정수 등식에서 최소 비영 위반량이 1이고 원래 목적함수의 전체 가능한 변동폭이 ΔF로 유계라면, 각 A_k > ΔF는 실행 가능한 해가 존재할 때 전역 최소해의 제약 충족을 보장하는 충분조건으로 사용할 수 있다. 다만 큰 벌점이 장치에서 좋은 결과를 보장하지는 않는다. 실제 계수 범위와 작은 사례의 전수 검증을 함께 사용한다. 비정수 제약은 스케일과 최소 위반량을 별도로 고려한다.

**정확성 통과 조건:** 원래 모형의 모든 실행 가능한 결정에 벌점 0인 표현이 존재하고, 벌점 0인 표현을 복원하면 원래 제약을 만족하며, 목적함수는 알려진 상수·스케일을 제외하고 일치해야 한다. 충분한 벌점에서 작은 사례의 최적값도 일치하는지 확인한다.

### 8.3 비교군과 공정한 비교 조건

| 비교군 | 역할 |
| --- | --- |
| 고전 MILP 또는 동등한 정확해법 | 작은 사례의 최적값·최적성 증명, 큰 사례의 최선 해와 하한 제공 |
| 적재 가능성을 지키는 근거리 우선 휴리스틱 | 단순한 운영 규칙의 기준선. 동률과 작업량 결정 규칙 고정 |
| 고전 QUBO 해법 | QPU와 같은 QUBO를 풀어 인코딩 영향과 장치 영향을 구분 |
| 실제 QPU | 같은 인코딩의 실행 성능과 자원 한계 측정 |
| 양자·고전 하이브리드, 사용 시 | 전체 시스템 결과를 별도 분류하여 비교 |

QPU 실행 전에는 같은 QUBO의 고전 해법과 시뮬레이션으로 인코딩을 검증한다. 시뮬레이터 결과를 실제 QPU 실험으로 표기하지 않는다. 네이티브 정수·제약을 지원하는 하이브리드 모형을 쓸 경우 직접 QUBO QPU 실험과 구분한다. [D-Wave 공식 모형 구분](https://docs.dwavequantum.com/en/latest/ocean/api_ref_dimod/models.html).

- 같은 인스턴스, 목표 재고, 초기 적재량, 복귀·방문 정책, 원래 목적함수로 평가한다. 제약을 단순화하거나 수량을 고정하면 별도 축소 문제로 표시한다.
- 장치에서 원래 논리 그래프를 직접 실행할 수 없다면 플랫폼별 배치·변환을 검증한다. 중성원자 기반 MIS 등 다른 네이티브 문제를 쓰려면 추가 변환과 복원 검증이 필요하다.
- 장치에 맞지 않아 분해할 경우 분해 규칙·고전 처리·후처리 시간까지 기록한다. 경로만 QPU에 맡긴 결과는 전체 수량·경로 동시 최적화의 직접 실행과 구분한다.
- 인코딩별 튜닝 예산을 맞추고 평가 인스턴스와 분리한다. 반복 실행으로 평균·중앙값·분산과 최선 해를 보고한다.
- 수리한 해를 보고할 경우 원표본의 실행 가능률과 수리 후 성능·수리 시간도 함께 보고한다.

### 8.4 평가 지표

| 측면 | 지표 |
| --- | --- |
| 원래 문제의 품질 | F, 이동거리·시간, 수거·배치량, 잔여 부족·과잉, 방문 수 |
| 실행 가능성 | 경로 연결, 모든 구간의 적재 한도, 재고·총량 보존, 제약별 위반량 |
| 기준 해와 차이 | 최적값을 증명한 사례의 목적값 차이·상대 차이. 미증명 사례는 최선 알려진 해·하한과 비교 |
| 인코딩 부담 | 논리 변수 수, 보조변수 수, 비영 이차항 수, 계수 범위 |
| 장치 부담 | 물리 자원 수, 배치 성공률, 플랫폼별 연결·체인 관련 지표 |
| 시간 | 전처리, 인코딩, 장치 배치, 튜닝, 대기, 실행, 복원·수리, 전체 경과시간 |
| 재현성 | 반복 횟수·난수 시드·설정·소프트웨어 버전·장치 식별자·실행일 |

최적값 F* > 0인 경우 상대 차이는 (F − F*) / F*로 계산하고, F* = 0이면 절대 차이를 보고한다. 실행 불가능한 표본의 낮은 에너지를 좋은 재배치 해로 평가하지 않는다. QPU 실행시간만 고전 알고리즘의 전체 시간과 비교하지 않으며 대기 포함·제외 시간을 함께 제시한다.

## 9. 단계별 실행계획

| 단계 | 수행할 작업 | 완료 기준·후속 산출물 |
| --- | --- | --- |
| 1. 설정 확정 | 출발지, 후보 선정, Q·Q_0, 목표 재고, 종료 정책, 비용 가중치를 결정 | 모든 설정과 출처·가정을 담은 인스턴스 명세 |
| 2. 작은 합성 사례 | 3~5개 대여소에서 수작업으로 가능한 경로와 적재 변화를 확인 | 빈 트럭, 수급 불일치, 용량 부족, 무작업 사례의 기대 결과 |
| 3. 공통 데이터·그래프 | 실제 재고 스냅샷과 위치 결합, 후보 추출, 전체 이동비용 행렬 계산 | 동일 입력으로 다시 만들 수 있는 그래프와 원자료 |
| 4. 고전 기준 해 | MILP와 적재 가능 근거리 우선 기준선 구현 | 실행 가능한 경로·작업량, 작은 사례의 최적성 확인 |
| 5. QUBO 인코딩 | 이진 자리값·원핫 모형 구축, 모든 보조변수와 벌점 기록 | 작은 사례에서 원모형과 해·목적값 일치 |
| 6. 고전 QUBO 검증 | 동일 QUBO를 고전 해법으로 반복 실행 | 인코딩별 실행 가능률·품질·변수 규모 비교 |
| 7. QPU 실행 | 자원 규모를 보고 장치 선택, 배치·샘플링·복원 | 실제 장치 실행 기록과 원표본·복원 결과 |
| 8. 비교·민감도 분석 | 대여소 수, 용량, 초기 적재량, 수급 상태, 비용·벌점 변화 | 동일 조건의 비교표와 적용 가능한 범위·실패 원인 |
| 9. 연구 정리 | 선행연구 대비 기여, 한계, 재현 절차 작성 | 검증된 결론과 다시 실행할 수 있는 연구 패키지 |

규모 확대는 대여소 3~5개에서 시작하여 8개·10개 등으로 단계적으로 시도하는 것을 제안한다. 이는 장치 수용 가능성을 보장하는 수치가 아니다. **대여소 수가 아니라 변환 후 전체 논리 변수와 장치 자원 수**를 확인하고 다음 규모를 정한다.

수급 시나리오는 공급·부족 총량이 비슷한 경우, 부족 우세, 과잉 우세를 포함한다. 반경 밖 대여소를 제외한 결과로 남는 부족량과 알고리즘의 성능 한계를 구분한다.

## 11. 다음 세션에서 바로 이어갈 작업

**현재까지의 상태:** 연구 방향과 수식·실험 초안이 정리되었다. 실제 데이터 수집, 코드 구현, 고전 최적해 계산, QUBO 동치 검증, 실제 QPU 실행은 아직 수행되지 않았다.

1. 이 문서의 확정 범위를 유지하면서 10절의 미확정 항목을 정한다. 사용자 지정값이 없으면 합성 데이터 검증용 설정임을 명시한다.
2. 7.6절의 작은 예시부터 경로·재고·적재량 보존을 확인한다. 이후 용량 부족과 구역 내 수급 불일치 사례를 추가한다.
3. 공통 인스턴스 형식을 `대여소 표 + 방향별 이동비용 행렬 + 트럭·정책 설정`으로 정하고, 원래 문제의 해를 검증하는 절차를 만든다.
4. 고전 기준 해를 확보한 뒤 같은 모형을 QUBO로 변환한다. QPU 종류를 정하기 전에 인코딩 후 자원 규모를 확인한다.
5. 고전·QPU 결과를 모두 `방문 순서, 수거·배치량, 구간별 적재량, 최종 재고, 비용 내역, 제약 위반`으로 복원하여 비교한다.
