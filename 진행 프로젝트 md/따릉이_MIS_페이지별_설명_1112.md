## 슬라이드 01. 연구 제목과 전체 목적 — 표지

### 일반 설명

- 연구 주제는 공공자전거 재배치 작업의 선택을 MIS로 표현하고, 중성원자 QPU와 고전 알고리즘으로 같은 문제를 푸는 것임.
- 작업 후보에는 자전거를 가져올 대여소, 가져다 놓을 대여소, 공통 운반량과 수행 시간이 정해져 있음. 계산의 대상은 이 후보들 중 어떤 작업을 수행할지 결정하는 것임.
- 각 작업이 옮기는 자전거 수를 같게 설정했으므로, 실행 가능한 작업을 많이 선택하면 총 운반량도 함께 증가함.
- QPU는 양자 계산을 수행하는 장치이고, 고전 알고리즘은 일반 컴퓨터에서 실행하는 비교 방법임. 양자 방식의 우수성을 가정하지 않고 결과와 구현 부담을 비교함.

### 양자 비전문가를 위한 쉬운 설명

- 자전거가 많은 대여소에서 부족한 대여소로 옮기는 일을 여러 개 준비해 놓았다고 생각하면 됨.
- 트럭은 한 대이므로 시간이 겹치는 일 두 개를 모두 할 수 없음. 같은 대여소를 중복 사용하는 작업에도 이번 연구의 제한을 적용함.
- **“서로 방해하지 않는 일을 최대한 많이 고르는 문제를 양자컴퓨터와 일반 컴퓨터가 각각 풀어 보고 비교하는 연구입니다.”**라고 설명하면 됨.
- 여기서 비교하는 것은 단순히 정답 여부뿐 아니라, 몇 개의 일을 골랐는지, 실제로 가능한지, 얼마나 많은 시간과 자원이 필요한지임.

## 슬라이드 02. 공공자전거 재배치의 배경 — 하단 1페이지

### 일반 설명

- 공공자전거는 대여와 반납이 지역과 시간에 따라 다르므로 대여소별 재고 불균형이 발생함.
- 자전거가 부족하면 대여가 어려워지고, 재고가 과도하게 집중되면 다른 대여소의 부족을 해소할 자원이 한곳에 남게 됨.
- 운영자는 트럭으로 자전거를 이동하여 대여소의 현재 재고를 목표 수준에 가깝게 조정함.
- 대여소 위치와 재고 자료에 목표 재고, 트럭 용량 및 작업시간을 결합하여 재배치 후보를 구성함. 목표 재고를 어떻게 산정할지는 구체적인 기준을 확정해야 함.

### 양자 비전문가를 위한 쉬운 설명

- A 대여소에는 자전거가 14대 있는데 필요한 수는 10대이고, B 대여소에는 6대밖에 없는데 필요한 수는 10대라고 가정해 보자.
- A의 남는 자전거를 B로 옮기면 두 곳의 상황을 함께 개선할 수 있음.
- 하지만 옮길 수 있는 시간과 트럭의 적재량에는 한계가 있음. 그래서 **“어디에서 어디로 옮기는 일을 먼저, 그리고 몇 개나 할 것인가?”**를 계산해야 함.
- 이 페이지는 양자 원리를 설명하는 장이 아니라, 연구가 해결하려는 현실의 운영 문제를 소개하는 장임.

## 슬라이드 03. 양자컴퓨터를 검토하는 이유 — 하단 2페이지

### 일반 설명

- 여러 작업은 각각 실행 가능하더라도, 수행 시간이 겹치거나 대여소 사용이 중복되면 함께 선택할 수 없음. 따라서 개별 작업보다 작업 조합을 평가해야 함.
- 이 배타관계를 충돌그래프로 표현하면, 함께 선택할 수 있는 작업의 최대 집합을 MIS로 정식화할 수 있음.
- 중성원자 장치에서는 가까운 원자의 동시 들뜸을 억제하는 Rydberg blockade를 MIS의 충돌 제약에 대응시키는 연구가 수행되어 있음(Ebadi et al., 2022).
- 이러한 물리적 대응을 실제 재배치 문제에서도 구현할 수 있는지, 결과의 품질과 장치 부담은 어떠한지 검증하기 위해 중성원자 QPU를 검토함.

### 양자 비전문가를 위한 쉬운 설명

- 어떤 두 일을 동시에 하면 안 된다는 규칙을, 양자 장치 안에서도 표현할 수 있는지가 출발점임.
- 중성원자 장치에는 가까운 두 원자가 특정 상태에 동시에 들어가는 것을 어렵게 만드는 현상이 있음. 이것이 “서로 충돌하는 작업은 함께 선택하지 않는다”는 규칙과 연결됨.
- 그래서 **“우리 문제의 규칙을 원자들의 상호작용으로 표현해서 풀어 볼 수 있겠다고 판단했습니다.”**라고 설명하면 됨.
- 이 대응이 있다고 해서 더 빠르거나 항상 정답을 얻는 것은 아님. 실제로 얼마나 잘 작동하는지 확인하는 것이 연구 질문임.

## 슬라이드 04. 공공자전거 재배치 선행연구 — 하단 3페이지

### 일반 설명

- 표 1은 재배치 문제에서 재고 기준, 차량 경로, 운반량과 운행 부담을 어떻게 다뤄 왔는지 보여줌.
- Schuijbroek et al.(2017)은 서비스 수준에 필요한 재고 구간과 차량 경로를 연결함. 본 연구에서는 과잉 및 부족 판정과 운영 제약을 설계하는 데 참고함.
- Rainer-Harbach et al.(2015)은 정적 재배치에서 경로와 운반량을 구성하고 탐색으로 개선하는 방법들을 비교함. 본 연구의 후보 구성과 운행 부담 평가에 참고함.
- Liang et al.(2024)은 시간에 따라 변하는 목표 재고와 재계획을 다룸. 정적 재고를 사용하는 이번 연구가 다루는 범위를 설명하는 데 참고함.
- 본 연구는 경로와 운반량을 모두 자유롭게 최적화하는 대신, 미리 구성한 동일 운반량 작업의 선택을 비교 대상으로 삼음.

### 양자 비전문가를 위한 쉬운 설명

- 이 표는 **“자전거를 옮기는 계획을 기존 연구에서는 어떻게 세웠는가?”**를 정리한 것임.
- 어떤 연구는 대여소마다 몇 대가 있어야 하는지를 중요하게 보고, 어떤 연구는 트럭이 어디를 어떤 순서로 방문할지를 중요하게 봄.
- 우리는 이 연구들을 참고해 가능한 작업을 먼저 만들고, 그중 함께 수행할 작업을 고르는 부분에 집중함.
- 발표에서는 논문 이름을 모두 읽기보다 **“기존 연구의 재고와 차량 제약을 참고하되, 이번에는 작업 조합을 선택하는 문제를 비교합니다.”**라고 말하면 됨.

## 슬라이드 05. 충돌그래프와 최대 독립집합 — 하단 4페이지

### 일반 설명

- 충돌그래프에서 노드는 작업 후보, 엣지는 두 작업의 동시 선택 금지를 의미함. 노드가 대여소 자체를 뜻하는 것은 아님.
- 독립집합은 선택된 노드 사이에 엣지가 없는 집합임. 최대 독립집합은 가능한 독립집합 중 노드 개수가 가장 큰 집합임.
- 본 연구는 모든 작업의 선택 보상을 동일하게 두는 비가중 MIS를 사용함. 거리는 작업시간과 후보 범위에, 재고는 운반 가능성에 반영함.
- 고전 비교군은 정확 기준을 제공하는 ILP, 확률적으로 탐색하는 SA, 노드 교환으로 개선하는 ILS임. 구체적인 역할은 하단 19페이지에서 설명함.

### 양자 비전문가를 위한 쉬운 설명

- 동그라미 하나를 해야 할 일 하나라고 생각하면 됨. 두 동그라미 사이에 선이 있으면 두 일을 함께 고를 수 없다는 뜻임.
- A와 B 사이에 선이 있고 B와 C 사이에도 선이 있지만 A와 C 사이에는 선이 없다면, A와 C를 함께 고를 수 있음.
- **“선으로 연결된 일은 같이 고르지 않으면서, 고른 일의 개수를 가장 많게 만드는 것이 MIS입니다.”**라고 설명하면 됨.
- 더 추가할 일이 없다는 것만으로 가장 많이 고른 것은 아닐 수 있음. 가능한 조합 전체에서 가장 많은 개수를 찾는 것이 목표임.

## 슬라이드 06. 중성원자 양자컴퓨팅의 원리 — 하단 5페이지

### 일반 설명

- 중성원자 QPU는 전기적으로 중성인 원자들을 광학 집게로 포획하고 배열한 뒤, 레이저로 에너지 상태를 제어하는 장치임. 광학 집게는 빛으로 원자를 붙잡는 장치라고 이해하면 됨.
- 원자의 바닥상태와 Rydberg 들뜬 상태를 계산에 사용함. Rydberg 상태는 원자가 높은 에너지 상태에 있어 원자 간 상호작용이 강해지는 상태임.
- 가까운 두 원자의 동시 들뜸이 억제되는 현상을 Rydberg blockade라고 함. 충분한 억제가 이루어지는 조건에서 MIS의 인접 노드 동시 선택 금지와 대응시킬 수 있음.
- 레이저 제어 중에는 중첩과 원자 간 상호작용을 포함한 양자 상태가 변화하며, 마지막 측정에서 하나의 상태 조합을 얻음.
- 일반적인 충돌그래프를 원자 사이의 거리만으로 구현할 수 있다고 가정하지 않음. 보조 원자가 필요하면 원래 MIS 목적을 보존하는지 검증해야 함.

### 양자 비전문가를 위한 쉬운 설명

- 원자를 아주 작게 배열하고, 레이저로 원자의 상태를 바꾸는 계산 장치라고 생각하면 됨.
- 계산이 끝난 뒤 측정한 두 상태를 “이 작업을 선택했다”와 “선택하지 않았다”에 연결해 읽음. 계산 중의 원자는 단순한 켜짐, 꺼짐 스위치만으로 설명되지는 않음.
- 가까운 원자 둘이 함께 들뜨기 어려운 성질을 이용해, 충돌하는 두 작업을 함께 고르기 어렵게 만드는 것임.
- 다만 **“충돌을 억제하는 규칙이 맞는지, 더 많은 작업을 선택하는 목적도 유지되는지까지 확인해야 합니다.”**라고 덧붙여야 함.

## 슬라이드 07. 연구 목적과 연구 질문 — 하단 6페이지

### 일반 설명

- 연구 목적은 동일 운반량의 재배치 작업을 MIS로 표현하고, 실제 QPU와 고전 알고리즘의 결과를 같은 조건에서 평가하는 것임.
- RQ1은 운영 제약과 독립집합의 대응 및 QPU에서의 목적 보존을 확인함. 즉, 원하는 운영 문제와 계산 장치가 실제로 푸는 문제가 일치하는지 묻는 질문임.
- RQ2는 후보 수와 충돌 밀도 변화에 따른 원자 자원, 구현 실패 및 실행 가능한 표본의 비율을 확인함.
- RQ3는 같은 문제에서 선택 작업 수, 최적해 도달률과 전체 계산비용을 비교함.

### 양자 비전문가를 위한 쉬운 설명

- 이 연구에서 확인할 것은 세 가지임.
- 첫째, **“우리가 만든 문제가 실제 트럭 운영 규칙을 제대로 담고 있는가?”**
- 둘째, **“그 문제를 양자 장치에 올릴 수 있고, 문제가 커지면 얼마나 많은 원자가 필요한가?”**
- 셋째, **“양자 장치와 일반 컴퓨터가 각각 몇 개의 일을 골랐고, 얼마나 안정적으로, 얼마의 비용으로 골랐는가?”**
- 아직 양자 방식이 이겼다는 결론을 제시하는 단계가 아니라, 무엇을 검증할지 정하는 페이지임.

## 슬라이드 08. 운영 가정과 연구 범위 — 하단 7페이지

### 일반 설명

- 트럭은 1대이며, 출발점, 적재 용량과 전체 계획기간을 고정함. 같은 시각의 대여소 재고를 하나의 문제 사례로 사용함.
- 계획기간 동안 외부 대여와 반납에 따른 재고 변화는 제외하는 정적 재배치를 가정함. 수요 변화의 영향을 통제해 계산 방식 자체를 비교하기 위한 설계임.
- 각 작업은 빈 트럭으로 출발하여 수거와 배송을 마친 뒤 같은 출발점으로 빈 트럭 상태로 복귀함. 따라서 시간상 겹치지 않는 작업을 차례대로 연결할 수 있음.
- 수거소와 배송소는 계획기간에 최대 한 작업에서만 사용함. 공통 출발점은 이 제한에서 제외하고, 출발점의 재고를 수거와 배송에 사용하지 않음.
- 이러한 복귀 정책, 동일 운반량과 대여소 사용 제한은 이번 연구의 가정임. 모든 현실적 재배치 운영을 표현하는 조건은 아님.

### 양자 비전문가를 위한 쉬운 설명

- 공정한 비교를 하려고 문제의 규칙을 먼저 고정하는 단계임.
- **“트럭 한 대가 같은 장소에서 빈 상태로 출발하고, 자전거를 옮긴 뒤 다시 돌아오는 일을 여러 번 수행한다고 가정합니다.”**라고 설명하면 됨.
- 각 일을 마칠 때 트럭의 위치와 짐 상태가 같으므로, 앞의 일이 끝난 다음 다른 일을 시작할 수 있는지 판단하기 쉬워짐.
- 또 같은 대여소를 여러 작업이 반복해서 사용하지 않게 제한함. 이러한 조건 안에서 가능한 일을 고르는 연구이며, 실제 현장의 모든 경로를 자유롭게 찾는 연구는 아님.

## 슬라이드 09. 입력자료와 과잉 및 부족 계산 — 하단 8페이지

### 일반 설명

- 대여소 ID로 위치와 재고 자료를 연결하고, 관측 시각과 중복과 결측을 확인함. 서로 다른 시간의 재고를 같은 시점처럼 섞지 않는 것이 중요함.
- 현재 재고를 $b_i$, 목표 재고를 $t_i$로 나타냄. 목표 재고는 운영자료나 평가기간 이전의 이력을 근거로 정하며, 구체적인 산정 방법은 확정이 필요함.
- 수거 가능한 과잉량과 배송할 부족량은 다음과 같이 계산함.

$$
E_i=\max(b_i-t_i,0),\qquad D_j=\max(t_j-b_j,0)
$$

- $E_i$는 대여소 $i$에서 가져올 수 있는 양, $D_j$는 대여소 $j$에 채울 양임. 두 값과 트럭 용량이 모두 공통 운반량 이상인 작업만 후보로 만듦.
- `max(값, 0)`은 부족한 곳의 과잉량이나 과잉인 곳의 부족량을 음수로 표시하지 않고 0으로 처리한다는 뜻임.

### 양자 비전문가를 위한 쉬운 설명

- 목표가 10대이고 현재 14대라면, 4대가 남으므로 수거할 수 있는 양은 4대임.
- 다른 곳의 목표가 10대이고 현재 6대라면, 채워야 할 양은 4대임.
- 한 번에 2대씩 옮긴다면 두 곳을 연결한 작업을 만들 수 있음. 반대로 가져올 수 있는 자전거가 1대뿐이라면, 2대를 옮기는 작업은 만들지 않음.
- **“실제로 수행할 수 있는 일만 계산기에 넣기 위해, 먼저 재고 자료를 확인하는 단계입니다.”**라고 설명하면 됨.

## 슬라이드 10. 작업 후보, 거리와 시간 — 하단 9페이지

### 일반 설명

- 작업 후보 $p$에는 수거소 $i$, 배송소 $j$, 시작시각 $a_p$와 공통 운반량 $q_0$가 정해져 있음. 기본 운반량은 2대이며, 같은 실험의 후보들은 모두 같은 양을 옮김.
- 운반량은 수거 가능한 양, 부족량과 트럭 용량 $Q$를 넘을 수 없음.

$$
q_p=q_0,\qquad 1\le q_0\le\min(E_i,D_j,Q)
$$

- 왕복 거리 $L_p$는 출발점 $s$에서 수거소, 배송소를 거쳐 다시 출발점으로 돌아오는 세 구간의 합임.

$$
L_p=d(s,i)+d(i,j)+d(j,s)
$$

- 작업시간 $\tau_p$는 이동시간, 상하차 시간과 두 대여소의 정차시간을 합한 값임. $v$는 속도, $h$는 자전거 1대의 수거 또는 배송 처리시간, $c$는 대여소 1곳의 정차시간임.

$$
\tau_p=L_p/v+2hq_0+2c,\qquad e_p=a_p+\tau_p\le H
$$

- $2hq_0$의 2는 수거와 배송 두 번의 처리를 뜻함. 종료시각 $e_p$가 계획기간 $H$를 넘는 후보는 제외함. 거리와 시간은 서로 맞는 단위를 사용해야 함.

### 양자 비전문가를 위한 쉬운 설명

- 한 작업을 **“9시에 출발해서 A에서 2대를 가져오고, B에 2대를 놓은 뒤 돌아오는 일”**처럼 구체적으로 적어 놓는 것임.
- 예를 들어 왕복 거리가 3km이고 속도가 시속 15km라면 이동시간은 12분임. 여기에 수거와 배송 처리 4분, 정차 2분이 더 들면 총 18분임.
- 9시에 시작하면 9시 18분에 끝남. 정해진 마감시간을 넘으면 이 작업은 후보에서 빠짐.
- 이 숫자는 계산 방법을 보여주는 예시임. 실제 연구에는 정한 거리 기준과 처리시간을 적용해야 함.

## 슬라이드 11. 충돌그래프 예시 — 하단 10페이지

### 일반 설명

- 두 작업의 시간이 겹치면 트럭 1대가 모두 수행할 수 없으므로 엣지를 연결함. 같은 수거소나 배송소를 사용해 대여소 1회 사용 조건을 어기는 작업 쌍에도 엣지를 연결함.
- 예시는 P1~P5의 시간 구간을 각각 `[0,2)`, `[1,3)`, `[2,4)`, `[3,5)`, `[4,6)`으로 설정함. `[0,2)`는 0부터 시작하여 2가 되기 직전까지라는 뜻임.
- P1과 P2, P2와 P3, P3과 P4, P4와 P5는 시간이 겹침. P1과 P5는 같은 수거소를 사용하는 추가 충돌이 있음. 이 관계를 연결하면 5개 노드의 고리가 됨.
- P1과 P3은 시간이 겹치지 않고 추가 충돌도 없으므로 함께 선택할 수 있음. 이 설명용 그래프의 최대 선택 개수는 2개임.
- 후보 단계에서 운반량과 개별 작업의 시간 조건을 검사하고, 그래프에서는 여러 작업을 함께 선택할 수 있는지를 검사함.

### 양자 비전문가를 위한 쉬운 설명

- P1이 9시부터 9시 20분까지이고 P2가 9시 10분부터 9시 30분까지라면, 두 일은 중간에 시간이 겹침. 트럭 한 대가 동시에 할 수 없으므로 두 점 사이에 선을 그림.
- P3이 9시 20분에 시작한다면 P1이 끝난 직후 수행할 수 있음. 두 작업이 같은 장소에서 시작하고 끝나므로 작업 사이의 추가 이동도 필요하지 않음.
- **“선이 연결된 일끼리는 같이 고르면 안 됩니다. 이 예에서는 P1과 P3처럼 선이 없는 두 일을 고를 수 있습니다.”**라고 설명하면 됨.
- 시간 중복을 눈으로 보고 판단하는 규칙을, 컴퓨터가 처리할 그래프로 바꾸는 과정임.

## 슬라이드 12. 모형의 실행 가능성과 검증 — 하단 11페이지

### 일반 설명

- 그래프에서 충돌이 없다는 것과 실제 운영 제약을 만족한다는 것이 일치해야 함. 이를 확인하는 것이 모형의 동치성 검증임.
- 개별 후보는 재고, 운반량, 적재 용량과 종료시각 조건을 통과함. 함께 선택된 후보는 시간과 대여소 사용이 중복되지 않아야 함.
- 모든 작업이 같은 출발점에 빈 트럭으로 복귀하고 대여소 사용이 중복되지 않는 가정이 작업 간 연결과 재고 검사를 단순화함.
- 작은 사례에서는 모든 부분집합을 열거하여 그래프 판정과 원래 운영 제약 검사 결과를 대조함. 목적값은 선택 작업 수로 재계산함.
- 이 대응은 정해진 후보와 운영 가정 안에서 성립하는지 확인하는 것임. 자유로운 모든 재배치 계획을 최적으로 푼다는 뜻은 아님.

### 양자 비전문가를 위한 쉬운 설명

- 컴퓨터가 규칙표에서 가능한 계획이라고 골랐는데 실제로는 트럭 용량을 넘는다면, 규칙표를 잘못 만든 것임.
- 그래서 작은 문제에서 가능한 조합을 전부 살펴보고, **“그래프에서 괜찮다는 조합이 실제 규칙으로 검사해도 괜찮은가?”**를 확인함.
- 시험문제의 정답을 비교하기 전에 시험문제 자체가 올바르게 만들어졌는지 검사하는 단계라고 생각하면 됨.
- 여기서 틀리면 양자와 고전 알고리즘을 아무리 비교해도 원래 원했던 운영 문제에 대한 답이 되지 않음.

## 슬라이드 13. 목적함수와 충돌 제약 — 하단 12페이지

### 일반 설명

- 선택 변수 $x_p$는 작업 $p$를 선택하면 1, 제외하면 0임. 목적함수는 선택한 작업의 개수를 최대화함.

$$
\max\sum_{p\in V}x_p
$$

- $V$는 후보 작업 전체의 집합임. 충돌 엣지 $(p,r)\in E$가 있는 두 작업은 최대 하나만 선택할 수 있음. 여기서 $E$는 앞의 과잉량 $E_i$와 달리, 그래프의 엣지 집합을 뜻함.

$$
x_p+x_r\le1\quad((p,r)\in E),\qquad x_p\in\{0,1\}
$$

- 선택 작업 집합을 $S$, 작업 수를 $N(S)$, 총 운반량을 $B(S)$라고 하면 다음 관계가 성립함.

$$
N(S)=\sum_{p\in V}x_p,\qquad B(S)=q_0N(S)
$$

- 정적 재고, 동일 운반량, 과잉 및 부족을 넘지 않는 운반 및 대여소 사용 제한 아래에서 부족량과 과잉량은 각각 $B(S)$만큼 감소함. 두 편차를 합한 감소량은 $2B(S)$임.
- 연구가 직접 최대화하는 것은 작업 수임. 이동거리와 운행비용의 최소화는 목적함수에 포함되어 있지 않으며 별도 평가함.

### 양자 비전문가를 위한 쉬운 설명

- 각 작업 옆에 선택하면 1, 선택하지 않으면 0을 적는다고 생각하면 됨. 이 숫자를 더하면 선택한 일의 개수가 나옴.
- 충돌하는 두 일을 모두 고르면 `1+1=2`가 되어 “합이 1 이하여야 한다”는 규칙을 어김.
- 한 작업당 2대씩 옮길 때 3개 작업을 고르면 총 6대를 옮김. 과잉 대여소들에서는 6대가 줄고, 부족 대여소들에서는 부족량이 6대 줄어듦.
- **“같은 양을 옮기는 일 중 서로 방해하지 않는 일을 최대한 많이 고릅니다. 이동거리까지 가장 짧게 만든다는 뜻은 아닙니다.”**라고 설명하면 됨.

## 슬라이드 14. MIS를 에너지 문제로 표현 — 하단 13페이지

### 일반 설명

- MIS를 논리적 에너지 최소화 문제로 표현함. 작업 선택에 대한 보상은 음수 항으로, 충돌 위반은 양수 벌점 항으로 나타냄.

$$
\mathcal{E}(x)=-\sum_{p\in V}x_p+P\sum_{(p,r)\in E}x_px_r,\qquad P>1
$$

- 작업 하나를 선택할 때 에너지가 1만큼 낮아짐. 충돌 엣지의 양 끝을 모두 선택하면 $x_px_r=1$이 되어 벌점 $P$가 더해짐.
- $P>1$이면 충돌에 참여한 노드 하나를 제거할 때 보상 1을 잃는 것보다 적어도 하나의 벌점 $P$를 없애는 이득이 큼. 따라서 최소 에너지 조합에는 충돌이 없어야 하며, 그중 작업 수가 가장 많은 조합이 MIS임.
- 다음으로 원자 좌표와 상호작용을 통해 논리 문제를 구현하는지 검사함. 대여소의 위도, 경도는 이동거리 계산용이고, 원자 좌표는 장치에서 충돌 관계를 구현하기 위한 별도의 좌표임.
- 보조 원자가 필요하면 실제 에너지와 복원 결과가 원래 작업 수 최대화 목적을 보존하는지 확인함. 논리 벌점 $P$와 물리적 상호작용은 자동으로 같아지는 값이 아님.

### 양자 비전문가를 위한 쉬운 설명

- 점수가 **낮을수록 좋은 규칙표**를 만든다고 생각하면 됨. 일을 하나 고를 때마다 점수에서 1을 빼고, 같이 하면 안 되는 일을 고르면 큰 벌점을 더함.
- 설명용으로 벌점을 3이라고 하자. 충돌 없는 두 작업을 고르면 점수는 `-2`임. 충돌하는 두 작업을 고르면 `-2+3=1`임. 낮은 점수가 좋으므로 충돌 없는 조합이 유리함.
- 이 규칙은 “많이 고르고 충돌은 피하라”는 요구를 숫자로 적은 것임.
- **“이 숫자 규칙을 실제 원자들의 움직임에서도 같은 의미로 구현할 수 있는지 확인합니다.”**라고 이어가면 됨. 원자 배치가 잘못되면 원하는 숫자 문제와 다른 문제를 계산할 수 있음.

## 슬라이드 15. 물리 모형과 원자 상태의 변화 — 하단 14페이지

### 일반 설명

- 이 페이지의 $H(t)$는 시간에 따른 원자 계의 에너지와 상태 변화를 기술하는 **해밀토니안**임. 앞에서 계획기간을 나타낸 $H$와는 다른 기호 사용임. $\hbar$는 환산 플랑크 상수로, 수식의 단위를 맞추는 상수임.
- 위상을 0으로 둔 전역 구동 모형은 다음과 같음. 여기서 $i,j$는 대여소가 아니라 물리 원자의 번호임.

$$
\frac{H(t)}{\hbar}=\frac{\Omega(t)}{2}\sum_i\sigma_i^x-\Delta(t)\sum_i n_i+\sum_{i<j}V_{ij}n_in_j
$$

| 기호 | 일반적인 의미 | 이 연구에서 이해할 역할 |
|---|---|---|
| $n_i$ | 원자 $i$의 들뜸 여부를 나타내는 연산자 | 측정된 들뜸 상태를 선택 정보로 읽는 기준 |
| $\sigma_i^x$ | 두 상태 사이의 전이를 나타내는 연산자 | 레이저가 상태를 바꾸는 구동을 표현 |
| $\Omega(t)$ | 전역 구동의 라비 각주파수 | 상태 전이를 유도하는 레이저 구동 세기 |
| $\Delta(t)$ | 전역 디튜닝 | 들뜬 상태의 에너지상 이득을 조절 |
| $V_{ij}$ | 원자 사이의 상호작용 계수 | 두 원자의 동시 들뜸에 에너지 부담을 부과 |

- 양의 디튜닝은 들뜬 상태를 에너지상 유리하게 만들고, 강한 상호작용은 가까운 두 원자가 함께 들뜨는 것을 어렵게 만듦. 실제 최종 상태는 구동 과정, 전체 상호작용과 잡음의 영향도 받음.
- 원자들을 바닥상태로 준비한 뒤 진폭과 디튜닝을 시간에 따라 조절하고, 종료 시 측정하여 비트열을 얻음. 유한한 시간에 실행하므로 최적해 관측을 보장하지 않음.
- 비엣지 원자 쌍 사이에도 잔여 상호작용이 있을 수 있음. 보조 원자가 있으면 여기된 원자의 총수 대신 디코딩한 원래 작업 수로 평가함.

### 양자 비전문가를 위한 쉬운 설명

- 이 긴 식은 세 가지 역할로 나누면 됨. **“원자의 상태를 바꾸는 힘, 선택 상태를 유리하게 만드는 조건, 충돌하는 선택을 어렵게 만드는 힘”**임.
- 첫째, 레이저로 원자의 상태를 변화시킴. 둘째, 레이저 조건을 바꾸어 어떤 상태가 에너지상 유리한지 조절함. 셋째, 가까운 원자끼리는 함께 들뜰 때 큰 에너지 부담을 받음.
- 이 조건들을 시간에 따라 바꾸고 마지막에 측정하면, 여러 작업 중 무엇이 선택되었는지에 해당하는 결과를 읽을 수 있음.
- 계산 중에는 원자들이 중첩과 상호작용을 포함한 양자 상태로 변화함. 모든 정답을 한꺼번에 읽는 방식은 아니며, 한 번 측정하면 하나의 비트열 표본을 얻음.
- 발표에서는 모든 기호를 읽기보다 **“앞의 보상과 벌점 규칙을 원자의 에너지 구조에 대응시키는 식입니다. 실제 대응 여부는 별도로 검증합니다.”**라고 설명하면 됨.

## 슬라이드 16. Pasqal 실행 환경 — 하단 15페이지

### 일반 설명

- 실행 대상은 Pasqal Cloud를 통해 접근 가능한 Fresnel 계열의 실제 중성원자 QPU임. 정확한 장비 ID와 지원 조건은 계정에서 조회해 확정하는 계획임.
- Python은 자료 처리와 실행 절차를 작성하는 언어임. Pulser는 원자 배치와 레이저 시퀀스를 정의하는 소프트웨어이며, pasqal-cloud는 클라우드 연결과 작업 제출에 사용함.
- Register는 어떤 원자를 어느 좌표에 놓는지, Layout은 원자를 포획할 위치의 틀을, Sequence는 어떤 제어를 언제 가할지를 정의한다고 이해하면 됨.
- 장치 ID, 원자 수와 좌표, 펄스 조건, 패키지 버전, 측정 횟수 및 제출 작업 ID를 저장하여 재현성을 확보함. 고전 비교군의 CPU, 메모리와 솔버 조건도 기록함.
- 에뮬레이터는 일반 컴퓨터에서 장치 동작을 모사하는 사전 점검 수단임. 에뮬레이터 성공을 실제 QPU 실험 성공으로 보고하지 않음.

### 양자 비전문가를 위한 쉬운 설명

- 역할을 네 개로 구분하면 쉬움. **Fresnel은 실제 계산 장비, Pasqal Cloud는 장비에 접속하는 서비스, Pulser는 장비에 줄 지시를 만드는 도구, Python은 전체 과정을 작성하는 언어**임.
- 내 컴퓨터에서 계산 요청서를 만들고 인터넷으로 장비에 보낸 뒤, 장비가 측정한 결과를 다시 받는 흐름임.
- 에뮬레이터는 실제 장비를 사용하기 전에 컴퓨터로 연습하는 것과 비슷함. 연습이 잘되었다고 실제 장비에서도 같은 결과가 보장되지는 않음.
- 이 페이지는 어떤 장비와 조건을 사용할 계획인지 설명함. 아직 확인되지 않은 장비 이름이나 수치를 실행 완료 정보처럼 말하면 안 됨.

## 슬라이드 17. QPU 실행과 결과 복원 — 하단 16페이지

### 일반 설명

- 일반 컴퓨터에서 재고 자료를 정리하고 작업 후보와 충돌그래프를 생성한 뒤, 물리적 구현 가능성을 확인한 원자 배치 및 펄스 시퀀스를 준비함.
- QPU는 준비된 조건에서 원자의 상태를 변화시키고 측정함. 실행 결과는 원자별 상태를 기록한 비트열과 각 비트열의 관측 횟수임.
- 보조 원자가 있으면 정해진 디코딩 규칙으로 원래 작업 변수에 복원함. 그 뒤 원래 운영 제약을 다시 검사함.
- 유효한 표본 중 작업 수가 가장 큰 해를 최종 계획으로 선정함. 작업 수가 같으면 사전에 정한 노드 ID 순서를 사용하며, 거리로 재선별하는 추가 목적은 두지 않음.
- 결과를 보고 펄스를 반복 조정하는 고전 변분 튜닝과 불가능 표본의 고전 수리는 적용하지 않는 설계임. 고전 비교군은 같은 MIS를 별도로 풂.

### 양자 비전문가를 위한 쉬운 설명

- 설명을 위해 원래 작업이 P1~P5이고 보조 원자가 없거나 이미 복원이 끝났다고 하자. `10100`이라는 결과는 P1과 P3을 고른다는 뜻임. 비트의 순서는 사전에 정한 작업 순서를 사용함.
- `11000`이라면 P1과 P2를 고른 것임. 앞의 고리 그래프에서는 두 작업이 충돌하므로 이 결과는 실패 표본으로 셈.
- 여러 번 얻은 결과를 모두 검사한 뒤, 실제로 수행할 수 있으면서 가장 많은 작업을 고른 결과를 사용함.
- **“일반 컴퓨터가 문제를 준비하고, 양자 장치가 선택 조합을 측정하며, 다시 일반 컴퓨터가 그 조합을 실제 작업으로 읽고 검사합니다.”**라고 설명하면 됨.

## 슬라이드 18. 데이터 수집과 실험 사례 선정 — 하단 17페이지

### 일반 설명

- 기본안은 출발 대여소 10곳, 평일 5일과 하루 2회 관측을 조합한 100개 재고 스냅샷임. 스냅샷은 특정 시점의 재고 상태를 저장한 자료를 뜻함.
- 후보 수는 8, 12, 16, 20개를 파일럿 규모로 두고, 반경과 계획기간을 바꿔 조건별 문제를 구성함. 이 규모는 구현 가능성을 점검하기 위한 계획임.
- 후보 부분집합은 사전 규칙과 고정 난수 seed로 만들고, 전체 후보 중 실제 실험에 포함한 비율을 기록함. seed는 무작위 선택을 다시 재현할 수 있게 하는 시작값임.
- QPU 사례는 후보 수와 충돌 밀도를 고려해 최대 12개를 선정하는 기본안임. QPU와 고전 알고리즘에는 동일한 후보, 공통 운반량과 충돌 관계를 제공함.
- 구현 실패 사례도 보고하여 실행 가능한 사례만 골라 성능을 과장하지 않음. 제시된 수량은 실제로 확보하거나 실행한 결과가 아님.

### 양자 비전문가를 위한 쉬운 설명

- 하루 한 번, 한 장소만 보면 우연히 쉬운 문제만 고를 수 있음. 그래서 여러 장소와 시간의 재고를 살펴보려는 것임.
- 각 상황에서 가능한 일을 만든 다음, 작은 문제부터 원자 장치에 올릴 수 있는지 확인함.
- 두 계산 방식에 문제를 다르게 주면 공정한 비교가 되지 않으므로, 똑같은 작업 목록과 금지 관계를 전달함.
- **“여러 상황에서 같은 시험문제를 두 방식에 주고 비교합니다. 아직은 실제 장치 구현을 확인하는 작은 규모의 실험부터 시작합니다.”**라고 설명하면 됨.

## 슬라이드 19. 반복 측정과 조건별 비교 — 하단 18페이지

### 일반 설명

- 시간 충돌만 있는 문제, 대여소 충돌만 있는 문제와 두 조건을 결합한 문제를 나누어 비교함. 동일한 노드 수라도 연결 구조가 다르면 풀이 난도가 달라질 수 있기 때문임.
- 시간 충돌만 있으면 최대 개수의 구간 스케줄링과 비교할 수 있음. 대여소 충돌만 있고 작업이 수거소, 배송소 쌍으로 표현되는 조건에서는 최대 매칭을 기준으로 사용할 수 있음. 복수 시간대가 같은 대여소 쌍에 있더라도 대여소 중복 사용 제한을 유지함.
- QPU는 사례당 1,000회 측정을 5개 독립 배치로 반복하는 기본안임. 하나의 배치는 한 묶음의 실험이며, 장치의 job당 측정 상한에 따라 여러 제출 작업으로 나눌 수 있음.
- 각 배치에서 첫 100, 300, 1,000개 표본까지 사용했을 때 얻는 품질을 추적함. 이 세 구간은 같은 배치에 포함된 누적 결과이므로 서로 독립적인 반복 실험으로 세지 않음.
- 목표 재고, 반경, 공통 운반량, 시간 격자와 후보 수를 바꾸어 결과의 민감도를 확인함. 고전 확률 알고리즘도 서로 다른 seed로 반복함.

### 양자 비전문가를 위한 쉬운 설명

- 후보가 10개인 문제라도, 서로 방해하는 일이 거의 없는 경우와 복잡하게 얽힌 경우는 다름. 그래서 일의 개수와 방해 관계를 함께 바꾸어 비교함.
- 양자 장치는 한 번 측정할 때마다 다른 결과를 줄 수 있으므로 여러 번 실행해야 함. **측정 1회는 선택 조합 하나를 얻는 것**이라고 생각하면 됨.
- 100번만 시도했을 때와 1,000번 시도했을 때 좋은 조합을 얻을 가능성이 얼마나 달라지는지 확인함. 같은 조건의 실험 묶음도 여러 번 반복해 우연의 영향을 살펴봄.
- 마지막으로 “2대씩 옮길 때만 잘되는가?”, “계획시간이나 주변 반경을 바꿔도 비슷한가?”를 점검함. 잘 나온 조건만 고른 결과가 되지 않도록 하는 단계임.

## 슬라이드 20. 고전 알고리즘 비교군 — 하단 19페이지

### 일반 설명

- **ILP(정수선형계획):** 작업 선택 변수를 0과 1로 두고 충돌 제약 아래에서 최대 작업 수를 계산함. 최적임을 증명한 경우 기준값으로 사용하며, 시간 내 증명이 끝나지 않으면 얻은 해와 상한을 함께 기록함.
- **SA(모의담금질):** 선택 비트를 바꾸며 탐색하고, 온도라는 제어값에 따라 에너지가 높아지는 이동도 확률적으로 허용함. 한정된 주변에서 개선이 막히는 상황을 벗어나기 위한 방법임.
- **ILS(반복국소탐색):** 가능한 해에서 선택 노드 1개를 충돌 없는 2개로 바꾸는 개선을 수행하고, 해를 교란한 뒤 다시 개선함. Andrade et al.(2012)의 비가중 MIS 탐색을 참고함.
- 비교군의 역할은 다름. ILP는 최적 기준과 증명 여부, SA는 기존 중성원자 MIS 연구에서 사용한 확률적 에너지 탐색, ILS는 독립집합 구조에 특화된 탐색을 대표함.
- 세 알고리즘과 QPU는 모두 같은 비가중 MIS를 풂. 알고리즘별 설정, 반복 및 종료 규칙을 사전에 정하고 기록함.

### 양자 비전문가를 위한 쉬운 설명

- 양자 장치를 평가하려면 비교 상대가 있어야 함. 여기서는 일반 컴퓨터의 서로 다른 세 풀이 방식을 사용함.
- ILP는 “더 많이 고를 방법이 정말 없는지”까지 확인하려는 기준 풀이임. 다만 문제와 시간 제한에 따라 그 확인이 끝나지 않을 수 있음.
- SA는 주변에서 더 좋은 해를 찾다가 막히면, 잠시 나쁜 방향으로도 움직여 다른 가능성을 찾아보는 방법임. 여기서 온도는 실제 컴퓨터의 온도가 아니라 탐색을 조절하는 숫자임.
- ILS는 **“지금 고른 일 하나를 빼고 다른 두 일을 넣을 수 있을까?”**를 검사해 개수를 늘리고, 막히면 조합을 흔들어 다시 찾는 방법임.
- 한 가지 비교 상대만으로 결론내리지 않도록 역할이 다른 방법들을 함께 사용하는 것임.

## 슬라이드 21. 평가 지표와 Gap — 하단 20페이지

### 일반 설명

- QPU와 고전 해를 같은 운영 제약 검사기로 검증함. 원표본 실행 가능률은 복원한 측정 표본 중 원래 조건을 만족한 표본의 비율임.
- 해의 품질은 원래 작업의 선택 개수, 최적 작업 수와의 격차 및 최적해 도달률로 평가함. 보조 원자는 선택 작업 수에 포함하지 않음.
- 최대 작업 수에 도달한 서로 다른 유효 조합은 모두 최적해로 인정함. 특정 비트열 하나만 정답으로 지정하지 않음. 비율을 보고할 때는 전체 표본 기준인지 유효 표본 기준인지 분모를 명시함.
- 증명된 최대 작업 수를 $N^*$, 얻은 유효 해의 작업 수를 $N$이라고 하면 다음과 같이 계산함.

$$
\operatorname{Gap}(\%)=100\times\frac{N^*-N}{N^*}
$$

- $N^*>0$일 때 사용하며, 최적값이 0이면 비율은 해당 없음으로 처리함. 최적값을 증명하지 못한 경우에는 최선 상한 기준 격차라고 구분함. 실행 불가능한 결과를 단순히 작업 수가 적은 유효 해처럼 평가하지 않음.
- 장치 자체의 실행시간과 자료 처리, 제출, 대기와 판독을 포함한 총경과시간을 나누어 보고함. 운반량, 재고 편차 감소량과 이동거리도 별도 평가함.

### 양자 비전문가를 위한 쉬운 설명

- 최적으로는 5개 일을 할 수 있는데 어떤 방법이 4개를 골랐다면, 1개가 부족함. 부족한 1개를 최적의 5개로 나누면 Gap은 20%임.
- 최적과 같은 개수를 골랐다면 Gap은 0%임. 다만 고른 작업이 실제로 모두 가능하다는 검사를 먼저 통과해야 함.
- 100번 측정해서 85번은 가능한 계획이었다면 실행 가능률은 85%임. 그중 서로 다른 계획이라도 최대 작업 수에 도달했다면 모두 최적 결과로 셈.
- **“얼마나 좋은 계획을 찾았는지, 실패는 얼마나 잦았는지, 결과를 받기까지 실제로 얼마나 걸렸는지를 함께 봅니다.”**라고 설명하면 됨.
- 장치가 계산한 시간만 짧아도 접속과 대기에 오래 걸릴 수 있으므로, 사용자에게 필요한 전체 시간도 중요함.

## 슬라이드 22. 연구의 한계와 해석 범위 — 하단 21페이지

### 일반 설명

- 매 작업의 출발점 복귀, 대여소 1회 사용과 동일 운반량은 작업 선택을 MIS로 표현하기 위한 운영 가정임. 자유로운 경로와 운반량을 허용한 계획보다 효율이 떨어질 수 있음.
- 작업 수를 최대화해도 같은 작업 수를 가진 여러 해의 이동거리는 다를 수 있음. 따라서 MIS의 최적성만으로 최소 비용이나 최고의 서비스 수준을 달성했다고 말할 수 없음.
- 정적 재고, 평균 속도와 제한된 후보는 실제 수요 및 교통을 단순화함. 선택된 후보 부분집합에서의 최적해를 서울 전체 문제의 최적해로 일반화하지 않음.
- 원자 배치, 보조 원자, 장거리 상호작용과 측정 오류가 결과에 영향을 줄 수 있으므로, 논리 문제의 어려움과 물리 구현의 실패를 구분함.
- 작은 파일럿의 성공은 해당 설정에서의 구현과 성능에 대한 증거임. 현장 개선 또는 일반적인 양자 우위의 증거로 바로 확대 해석하지 않음.

### 양자 비전문가를 위한 쉬운 설명

- 이번 실험은 실제 운영의 모든 복잡한 상황을 그대로 넣은 것이 아니라, 비교할 수 있도록 규칙을 정한 작은 실험임.
- 시험에서 일을 3개 골랐다고 해서 실제 현장에서 기름값도 가장 적게 든다는 뜻은 아님. 같은 3개라도 이동거리는 다를 수 있음.
- 자전거 재고가 실험 중 바뀌거나 교통이 막히면 계획도 달라질 수 있음. 이번 결과가 어느 조건에서 나온 것인지 함께 설명해야 함.
- **“우리가 확인한 범위 안에서 말하고, 그 밖의 효과는 후속 검증이 필요하다고 구분하는 페이지입니다.”**라고 설명하면 됨.

## 슬라이드 23. 수행 계획과 예상 기여 — 하단 22페이지

### 일반 설명

- 1~2주에는 입력자료, 목표 재고, 공통 운반량과 후보 규칙을 정하고, 운영 제약과 그래프의 대응을 작은 사례로 검증하는 계획임.
- 3주에는 원자 배열과 전역 펄스가 장치 조건 및 MIS 목적을 만족하는지 확인함. 구현이 성립하지 않은 사례는 실패 원인을 기록함.
- 4~5주에는 같은 사례로 QPU와 고전 비교군을 독립 실행하고, 6주에는 작업 수 격차, 실패율과 민감도를 분석하는 계획임.
- 예상 기여는 재배치 작업을 비가중 MIS로 표현하는 적용 조건, 실제 중성원자 구현 범위와 자원 부담, 고전 비교군 대비 품질과 비용을 제시하는 것임.
- 입력자료, 규칙, 실행 로그와 분석 코드를 함께 정리해 결과를 다시 확인할 수 있도록 함. 주차별 내용은 완료 실적이 아니라 수행 계획임.

### 양자 비전문가를 위한 쉬운 설명

- 순서는 **문제를 제대로 만들기, 양자 장치에 올릴 수 있는지 확인하기, 두 방식으로 풀기, 결과를 비교하기**임.
- 처음부터 양자 장치를 실행하는 것보다 먼저 문제와 규칙이 맞는지 검사해야 함. 그다음 실제 장비에서 구현 가능한지를 확인함.
- 최종적으로는 “어떤 문제를 어느 정도까지 구현할 수 있었고, 얼마나 많은 일을 골랐으며, 어떤 부담이 있었는가?”를 설명하려는 것임.
- 양자 방식이 더 잘 나오는 경우뿐 아니라 잘되지 않는 조건과 원인을 밝혀도, 적용 범위를 이해하는 데 필요한 결과가 됨.

- **Andrade et al.(2012):** 비가중 MIS의 빠른 국소탐색과 반복 탐색 연구. ILS 비교군의 근거로 활용함.

### 양자 비전문가를 위한 쉬운 설명

- 발표 중에는 서지사항을 전부 읽기보다 **“재배치 문제의 설정은 운영 연구를, 고전 비교군은 MIS 탐색 연구를 참고했습니다.”**라고 설명하면 됨.

## 슬라이드 25. MIS와 양자 최적화 참고문헌 — 하단 24페이지

### 일반 설명

- **Lucas(2014):** 조합최적화의 선택과 제약을 에너지 모형으로 표현하는 근거. 본 연구의 보상 및 충돌 벌점 정식화를 설명하는 데 활용함.
- **Ebadi et al.(2022):** 실제 Rydberg 원자 배열의 MIS 실험과 고전 SA 비교 사례. 중성원자 QPU 적용을 검토할 실험적 배경임.
- **Nguyen et al.(2023):** 장치의 기하학적 연결 제약을 넘어 다양한 연결성의 문제를 원자 배열에 대응시키는 연구. 그래프 변환과 자원 증가를 검토하는 배경임.
- **Andrist et al.(2023):** 다양한 고전 솔버와 그래프 구조에 따른 난도를 분석한 연구. 강한 비교군과 구조별 성능 평가의 필요성을 설명하는 데 활용함.
- 이 논문들이 현재 연구의 실제 장비와 전역 제어 설정에서 임의의 재배치 그래프를 그대로 구현할 수 있음을 증명한 것은 아님. 구현 가능성과 목적 보존은 이번 연구에서 확인해야 함.

### 양자 비전문가를 위한 쉬운 설명

- 네 논문은 서로 다른 질문에 도움을 줌.
- Lucas는 “문제를 원자가 다룰 수 있는 에너지 규칙으로 어떻게 적을까?”, Ebadi는 “실제 원자 장치로 MIS를 해 본 사례가 있을까?”에 연결됨.
- Nguyen은 “원하는 연결 모양을 장비에 어떻게 옮길까?”, Andrist는 “일반 컴퓨터와 얼마나 공정하게 비교해야 할까?”에 연결됨.
- **“이미 알려진 원리를 참고하지만, 우리 데이터와 장비 조건에서도 성립하는지는 직접 검증합니다.”**라고 설명하면 됨.

## 슬라이드 26. 성능 평가와 공식 자료 — 하단 25페이지

- 학술논문은 연구 논리와 평가 근거, 공식 문서는 실제 장비 사용 조건과 절차를 뒷받침함.

### 양자 비전문가를 위한 쉬운 설명

- 연구 논문은 “왜 이런 비교를 하는가?”에 대한 근거이고, 공식 장비 문서는 “실제로 장비를 어떻게 사용해야 하는가?”에 대한 설명서임.
- 서울 자료는 문제를 만드는 재료이고, Pasqal 문서는 장비 사용설명서라고 생각하면 됨.
- **“문제의 데이터, 비교 방법, 장비 사용 조건의 출처를 각각 명확히 남겨 다른 사람도 확인할 수 있게 합니다.”**라고 설명하면 됨.

| 재배치 | 남는 곳에서 부족한 곳으로 자전거를 옮기는 일 |
| 작업 후보 | 경로, 운반량과 시간이 정해진 수행 가능한 일 하나 |
| 충돌 | 두 일을 같은 계획에 함께 넣을 수 없는 관계 |
| 노드 / 엣지 | 일을 나타낸 점 / 충돌 관계를 나타낸 선 |
| MIS | 충돌 없이 고를 수 있는 일을 최대한 많이 고르는 문제 |
| 실행 가능해 | 정한 재고, 적재 및 시간 조건을 모두 지키는 계획 |
| 고전 알고리즘 | 일반 컴퓨터에서 문제를 푸는 방법 |
| QPU | 실제 양자 계산을 수행하는 장치 |
| 큐비트 | 양자 정보를 표현하는 기본 단위. 이 장치에서는 원자의 두 에너지 상태를 계산에 사용함 |
| 중성원자 | 전기적으로 중성인 원자 |
| 광학 집게 | 빛으로 원자를 붙잡는 장치 |
| 바닥상태 | 계산에 사용하는 두 상태 중 낮은 에너지 쪽의 상태 |
| Rydberg 상태 | 원자가 높은 에너지로 들떠 원자 간 상호작용이 강해지는 상태 |
| 여기 / 들뜸 | 원자가 높은 에너지 상태로 전이하는 것 |
| Rydberg blockade | 가까운 두 원자의 동시 들뜸이 억제되는 현상 |
| 펄스 | 정해진 시간 동안 원자를 제어하는 레이저 신호 |
| 진폭 / 라비 주파수 | 원자 상태 전이를 유도하는 구동 세기를 표현하는 값 |
| 디튜닝 | 레이저와 원자의 전이 사이 주파수 차이. 원자의 에너지상 선호를 조절하는 제어값 |
| 전역 제어 | 같은 제어를 원자 배열 전체에 적용하는 방식 |
| 해밀토니안 | 원자 계의 에너지 구조와 시간에 따른 상태 변화를 기술하는 수학적 모형 |
| 임베딩 | 논리적 그래프의 관계를 장치에서 구현할 원자 배치와 상호작용으로 옮기는 과정 |
| 보조 원자 | 원래 작업 외에 문제의 관계를 구현하기 위해 추가하는 원자 |
| 측정 / shot | 준비와 제어 뒤 원자 상태를 읽어 결과 표본 하나를 얻는 실행 |
| 비트열 | 측정 상태를 0과 1로 정해진 순서에 따라 나열한 결과 |
| 디코딩 | 측정 결과를 원래 작업 선택 정보로 되돌리는 것 |
| 에뮬레이터 | 일반 컴퓨터에서 양자 장치 동작을 모사하는 소프트웨어 |
| seed | 무작위 선택이나 탐색을 재현할 수 있게 지정하는 시작값 |
| 인스턴스 | 재고, 작업 후보와 충돌 조건이 정해진 문제 사례 하나 |
| 민감도 분석 | 입력과 설정을 바꾸었을 때 결과가 얼마나 달라지는지 확인하는 분석 |
| 양자 우위 | 명확한 문제 및 자원 기준에서 양자 방식이 적절한 고전 비교보다 우수하다고 입증한 상태 |

## 방법론 선택을 설명할 때 지킬 구분

- **문헌에서 확인한 배경:** 정적 및 동적 재배치의 구분, MIS의 에너지 정식화, 중성원자 MIS 실험, 고전 SA 및 ILS 비교의 근거.
- **이번 연구의 설계 선택:** 동일 운반량, 매 작업 후 복귀, 대여소 1회 사용, 사전 고정 펄스 규칙, 고전 수리 없이 원표본 평가.
- **현재 기본안인 수치:** 작업당 2대, 100개 스냅샷, 후보 8, 12, 16, 20개, 최대 12개 QPU 사례, 배치당 1,000회 측정과 5개 배치.
- **추가 확정이 필요한 항목:** 목표 재고 산식, 거리 및 시간 계수, 실제 장비 ID, 원자 배치 알고리즘, 구체적인 펄스 일정과 측정 예산.
- 위 수치와 정책을 특정 논문에서 가장 좋다고 권장한 값처럼 설명하지 않음. 연구 목적에 맞춰 정한 이유와 바꾸어 검증할 방법을 설명함.

## 발표에서 피해야 할 오해

- “노드는 대여소다”라고 설명하지 않음. 이 연구의 노드는 **시간과 운반량이 정해진 재배치 작업**임.
- “최적해는 이동거리가 가장 짧은 계획이다”라고 설명하지 않음. 여기서는 **선택 작업 수**가 최적성 기준임.
- “대여소의 위도, 경도를 그대로 원자 좌표로 사용한다”라고 설명하지 않음. 두 좌표는 역할이 다름.
- “원자 간 억제가 있으므로 충돌 표본이 절대 나오지 않는다”라고 설명하지 않음. 유한한 제어와 장치 오차의 영향을 검사해야 함.
- “양자컴퓨터가 모든 조합의 정답을 한 번에 읽는다”라고 설명하지 않음. 측정 한 번에 얻는 것은 비트열 표본 하나임.
- “에너지가 낮은 원자 상태면 원래 MIS도 자동으로 최적이다”라고 설명하지 않음. 물리 구현과 원래 목적의 대응이 확인되어야 함.
- “작은 사례에서 좋은 결과가 나왔으니 양자 우위가 입증됐다”라고 설명하지 않음. 범위, 비교군과 시간 기준을 명시해야 함.
